关于 pitboard

pitboard 是一张举给汽车行业从业者的「pit 板」：每天把开源项目、 行业资讯、前沿论文抓到一起，聚簇去重，按独立来源数与时间衰减算出热度， 把真正在发生的事顶到最上面。

它怎么工作

  • 抓取 — RSS 媒体源、GitHub 汽车话题仓库、arXiv 论文检索，全部免 key。
  • 聚簇 — 中英分词（CJK 二元语法）+ Jaccard 相似度，同一事件的多方报道并成一条。
  • 热度 — 独立来源越多越靠前，48 小时窗口内按新旧衰减；可选用 OpenAI 兼容 LLM 把头条翻译成中文摘要。
  • 出刊 — 每日定时生成一期刊物，写进 data/ 归档，站点与 API 同步刷新。

给 Agent 的出口

  • /rss.xml — RSS 订阅
  • /api/v1/latest.json — 最新一期 JSON（ /api/v1/digest/2026-10-13.json 按日期取）
  • /daily/<date>.md — Markdown 日报
  • /llms.txt — 站点索引
  • /api/events — SSE 出刊推送

自托管

一个 Racket 进程，零外部依赖（无数据库）：
raco pkg install --auto https://github.com/turinglambdaai/pitboard.git
raco pitboard fetch && raco pitboard serve --port 8090
