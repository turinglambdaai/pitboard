# Read the automotive daily board

**English** · [简体中文](READING.zh-CN.md)

[Open the reading site](https://pitboard.jrtx.site/)

## Reading path

Open the latest edition and check its edition/generated date before treating it as current. Open the original sources for claims that matter. Use topics and weekly/monthly archives to follow a subject; subscribe at /rss.xml rather than polling the whole website.

## Free access and content status

Reading is free and needs no account. Ranking/deduplication can merge unrelated stories or miss developments. Optional AI-generated headlines/summaries may be wrong; independent sources, not a score, establish a claim. Scheduled publication can fail; an old edition is not today’s news.

## Privacy and local data

The static website and self-hosted server have different capabilities: a Pages export does not provide a running SSE listener or MCP process. Site scripts currently include Baidu analytics. External source links have their own policies. Local saved items depend on browser storage and can be cleared; keep important source URLs separately.

## Corrections, feedback and recovery

Report a wrong cluster, stale edition or broken source with the edition date, story/source URL and expected correction. Do not upload private source credentials. Self-hosting operators back up data/ and config/ and rebuild the static site from those sources; preserve the previous successful export if fetching fails.
